# dviewer

[한국어](README.md) | [English](README.en.md)

마크다운·JSON·YAML·TOML·XML·CSV·TSV·텍스트/로그를 읽기 위한 데스크톱 뷰어. Tauri v2 + Rust 백엔드 + Svelte 5 프론트엔드. 인터페이스는 한국어·영어·일본어·중국어(간체)를 지원합니다.

여덟 가지 형식이지만 읽는 방식은 **셋**입니다. 형식마다 화면을 만들면 여덟 벌을 따로 손봐야 하고, 그중 일곱은 늘 뒤처집니다.

| 보기 | 형식 | 하는 일 |
| --- | --- | --- |
| 글 | 마크다운 | GitHub 수준 렌더링(표·체크박스·각주·알림 블록), 코드 구문 강조, Mermaid, KaTeX. 원문/렌더 토글 |
| 트리 | JSON · JSONL/NDJSON · YAML · TOML · XML | 접기/펼치기, 키·값·경로 검색, 깊이별 가이드선, 키/값 표, 경로 팝오버, 우클릭 복사 |
| 표 | CSV · TSV · 텍스트/로그 | 고정된 머리글과 행 번호, 끌어서 조절하는 열 너비, 칸 단위 검색과 복사. 텍스트는 한 줄이 한 행인 1열 표 |

- 500MB급 JSON·CSV와 200MB급 로그를 통째로 메모리에 올리지 않고 다룹니다. 자세한 수치는 [검증과 성능](doc/verification.md)에 있습니다.
- 파일 선택, 드래그 앤 드롭, URL, 붙여넣기 네 경로로 열 수 있고 탭으로 여러 문서를 동시에 봅니다.
- 형식은 확장자로 정하고(판별되지 않으면 텍스트), 문자 인코딩(UTF-8 · CP949/EUC-KR · UTF-16 등)은 내용으로 판별합니다. 둘 다 도구 모음에서 언제든 바꿀 수 있습니다.
- 다크/라이트(기본 자동), 인터페이스 배율, 인터페이스·본문 글자 크기, 시스템 글꼴 목록에서 고르는 본문·코드 글꼴을 지정할 수 있습니다.

## 필요 환경

- Node.js 20 이상 (개발 기준 24), npm
- Rust 1.85 이상 — comrak과 ureq이 요구하는 하한입니다 (개발 기준 1.94)
- [Tauri v2 사전 요구사항](https://v2.tauri.app/start/prerequisites/) — Windows는 WebView2와 MSVC 빌드 도구, Linux는 `webkit2gtk`

## 실행

```bash
npm install && npm run tauri dev
```

배포본을 만들려면:

```bash
npm run tauri build
```

`src-tauri/target/release/` 에 실행 파일이, `bundle/msi`·`bundle/nsis` 에 설치본이 생성됩니다.

## 명령줄

```bash
dviewer report.md                      # 위치 인자
dviewer --open="C:/데이터/큰파일.json"
dviewer --open-url=https://example.com/data.json
dviewer --new --open=a.csv             # 탭이 아니라 새 창으로
```

두 번째 실행은 창을 만들지 않고 이미 돌고 있는 프로세스의 **현재 창에 탭으로** 붙습니다. `--new` 를 주면 그때만 창을 하나 더 만듭니다. 동작 원리는 [설계와 구조](doc/architecture.md#명령줄-그리고-이미-열려-있는-창)에 있습니다.

## 알려진 한계

- JSON 파일은 4GB까지입니다 (오프셋이 `u32`).
- 검색은 리터럴 문자열이며, 대소문자 무시는 ASCII 범위에서만 동작합니다. 정규식과 JSONPath 표현식은 아직 없습니다 — 경로 검색은 `$.items[3].name` 같은 경로 문자열에 대한 부분 일치입니다.
- 마크다운 렌더링은 16MB까지입니다. 그보다 큰 파일은 열리지 않습니다.
- 펼침 깊이 프리셋은 9까지이며 기본값도 9입니다. 그보다 깊은 단계는 개별 노드를 펼쳐서 봅니다.
- 파일을 mmap 하므로, 열어 둔 파일이 밖에서 바뀌면 다시 열어야 합니다. 내용만 바뀐 경우는 읽던 값이 섞여 보이는 정도이지만, **파일이 잘리면 Linux·macOS 에서는 프로세스가 그대로 죽습니다**(SIGBUS). Windows 는 매핑이 열려 있는 파일의 축소를 OS 가 거부하므로 해당하지 않습니다.
- 마크다운의 원격 이미지를 허용합니다. `img-src` 에 `https:` 가 들어 있어 배지 같은 것이 그대로 보이는 대신, 문서를 열었다는 사실이 그 이미지를 주는 서버에 남습니다. 문서가 웹에서 보이는 그대로 보여야 한다고 판단한 결과입니다.
- 문서 편집·저장 기능은 없습니다. 읽기 전용 뷰어입니다.
